# Jetstar

> Jetstar Airways Pty Limited (ABN 33 069 720 243) is the Melbourne-based low-cost carrier of the Qantas Group. Jetstar operates a real, long-running partner API — it calls it, literally, "the Jetstar API" — but it is not a public developer product: it is the Navitaire New Skies (NSK 4.6) SOAP/WCF web service hosted on the vendor's own domain at jqapi.navitaire.com, gated behind IATA accreditation, separate Jetstar approval, a client certificate and IP allow-listing. There is no public developer portal, no OpenAPI or WSDL, no self-serve signup, and no bulk export operation.

This file was generated by API Evangelist from the Jetstar catalog entry and the artifacts in this repository. Jetstar publishes no llms.txt of its own (apiblog.jetstar.com answers a catch-all login page for /llms.txt).

## What this API is

- Protocol: SOAP 1.x / WCF over HTTPS, XML payloads, .svc service endpoints (e.g. UtilitiesManager.svc)
- Platform: Navitaire New Skies, version NSK 4.6 (Jetstar has been a New Skies customer since the 2009 Open Skies cutover)
- Production base URL: https://jqapi.navitaire.com
- Test base URL: https://soapapir4y.test.jq.navitaire.com
- Not IATA NDC. Not REST. No OpenAPI, no published WSDL, no GraphQL, no MCP server, no webhooks.
- Operations named in Jetstar's own published partner documentation: GetAvailability, GetTripAvailabilityWithSSR, PriceItinerary, GetItineraryPrice, GetSSRAvailability, GetStationList, AddPaymentToBooking, BookingCommit, GetBooking, UpdatePassengers

## How to get access

- [Become a Registered Travel Agent](https://www.jetstar.com/us/en/travel-agents/why-become-a-registered-travel-agent-with-jetstar): the entry point; accept the Jetstar Travel Agent Terms and Conditions
- [BSP settlement requirements](https://www.jetstar.com/us/en/travel-agents/information-centre/bsp-settlement): IATA GoStandard or GoGlobal accreditation; API access requires separate Jetstar approval
- [API registration](https://apiblog.jetstar.com/api-registration/): partner portal registration form (gated)
- [Partner portal](https://apiblog.jetstar.com/): "Jetstar API — Your Guide on Jetstar New Skies API"; every page redirects to /login/
- Support: apisupport@jetstar.com (API technical), sales@jetstar.com (commercial)
